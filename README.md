# Tic-tac-toe in C

A terminal **tic-tac-toe** game: you play `X` against the computer.

## Features
- 3×3 board drawn in the terminal after every move
- Input validation (cell inside the board and still free)
- The computer picks a random free cell
- Detects wins on rows, columns and diagonals, and a tie when the board is full
- Asks whether to end the game or play another round

## Build and run
```bash
gcc *.c -o tiktaktoe
./tiktaktoe
```

**Stack:** C
